# Aplikasi Pembuatan SKP Pegawai ASN

Aplikasi cetak SKP kini telah diperbarui! Dari yang awalnya hanya template cetak statis, sekarang aplikasi ini telah menjadi aplikasi utuh yang dilengkapi dengan **Formulir Input Data Dinamis**.

## Pembaruan Fitur

1.  **📝 Mode Edit Data**: Ini adalah halaman beranda baru saat Anda membuka aplikasi. Anda akan disajikan formulir lengkap untuk mengisi "Informasi Umum", "Data Pegawai", "Data Pejabat", daftar "Hasil Kerja Utama", hingga "Lampiran".
2.  **📄 Mode Preview & Cetak**: Mode ini merender hasil ketikan Anda di form tadi ke dalam 11 halaman dokumen resmi SKP yang siap dicetak persis seperti PDF asli.

> [!TIP]
> **Penyimpanan Otomatis (Auto-Save)**
> Semua teks yang Anda ketik, tambah, atau hapus di dalam form akan **otomatis tersimpan** di browser Anda (*Local Storage*). Jika Anda tidak sengaja menutup tab atau me-refresh halaman, data Anda tidak akan hilang!

## Cara Menggunakan Aplikasi

1.  Buka folder `[skp-app](file:///C:/Users/Myska/.gemini/antigravity/scratch/skp-app)`.
2.  Klik ganda pada file `index.html` untuk membukanya di browser (Chrome/Edge).
3.  Anda akan langsung berada di halaman **📝 Edit Data**.
4.  **Mengubah Data**: Cukup hapus teks yang ada di kotak input dan ketik data yang baru.
5.  **Menambah Data**: Gulir ke bawah hingga menemukan bagian *Hasil Kerja Utama* atau *Lampiran*. Klik tombol hijau `+ Tambah Hasil Kerja` atau tombol `+` kecil untuk menambah baris baru.
6.  **Menghapus Data**: Klik tombol merah `Hapus` atau `X` di sebelah item yang ingin Anda hapus.
7.  Setelah selesai mengisi, klik tab **📄 Preview & Cetak** di bagian atas layar.
8.  Tampilan akan berubah menjadi format dokumen.
9.  Klik tombol biru **🖨️ Cetak Dokumen** di pojok kanan bawah, pastikan orientasi kertas adalah *Landscape*, lalu cetak!
